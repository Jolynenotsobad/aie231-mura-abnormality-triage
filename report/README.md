# Report

This directory will contain the technical report (PDF) and presentation slides for the final submission.

## Expected contents (Checkpoint 4)

- `report.pdf` — 8–10 page technical report in IEEE conference format
- `slides.pdf` — presentation slides (10-minute pitch)

## Report structure

1. Abstract
2. Introduction and problem statement
3. Dataset and exploratory analysis
4. Methodology: preprocessing, baselines, architectures with hand parameter counts
5. Experiments: setup, hyperparameter studies, ablation studies
6. Results and error analysis
7. Deployment: inference pipeline and demo
8. Limitations, ethical considerations and future work
9. Team contributions table
10. References
